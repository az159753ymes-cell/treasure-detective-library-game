# 尋寶記世界任務遊戲

供國中生在圖書館新書展使用的平板闖關遊戲。學生選擇偵探、接收任務密信，再搭機前往伊拉克，依線索尋找《伊拉克尋寶記》實體書。

## 線上遊玩

[開啟 GitHub Pages 遊戲](https://az159753ymes-cell.github.io/treasure-detective-library-game/)

## 在本機開啟

直接開啟 `index.html`，或以靜態網站伺服器提供專案資料夾。完整流程與擴充案件方式請見 [教師使用說明](教師使用說明.md)。

## 專案內容

- `index.html`：遊戲介面、案件資料與互動流程。
- `assets/`：角色、世界地圖、偵探事務所場景與飛機圖片。
- `教師使用說明.md`：試行方式與新增案件說明。

本 repository 公開於 GitHub Pages；`backups/` 備份不納入版本控制。

伊拉克示範案加入章節閱讀回報與教師 Excel 後台。Firebase 尚需由教師自行建立並設定；步驟見 [Firebase後台設定說明.md](Firebase後台設定說明.md)。未完成設定時，學生紀錄不會被假裝保存。
